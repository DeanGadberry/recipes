Open a recipe request

Opens a short form — paste the URL and submit. It's picked up automatically within a minute or two.

From the GitHub mobile app

  1. Open the GitHub app and go to the DeanGadberry/recipes repo.
  2. Tap Issues, then the + to start a new one.
  3. It opens straight into the "Recipe request" form (it's the only option) — paste the URL in the first field.
  4. Tap Submit. That's it — no need to check back unless something goes wrong, in which case it'll leave a comment on your issue explaining why.
